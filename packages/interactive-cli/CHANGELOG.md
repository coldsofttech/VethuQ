# Changelog

All notable changes to `vethuq-interactive-cli`.

## [Unreleased]

### Changed (installer)
- Start > Programs > VethuQ also has `Uninstall VethuQ Interactive CLI`.
- The Start menu entry is now Start > Programs > VethuQ > VethuQ Interactive CLI, and there is an optional desktop shortcut, on by default.

### Documented
- The `Licence` menu (install, show, code, request), built from the `vethuq licence` commands.

### Documented
- Add-on settings (`settings > addons`) and the stand-ins for add-ons that are not running appear in the menus, built from the command tree.

### Documented
- The `Catalog` menu, built from the `vethuq catalog` commands.

### Documented
- The README says how the update check applies to the shell.

### Added
- The interactive shell: arrow-key menus generated from the `vethuq` command tree, guided search, the
  banner and logo. `vethuq` with no command opens it when installed and run in a terminal.
